# Jiang 0.6.1

Jiang 0.6.1 adds directory modules and improves navigation across package boundaries in the language server.

## Directory modules

Declare a directory module in its `package.jiang` and choose a separate source entry point.

```jiang
#package {
    type = .module;
    root = "math.jiang";
}
```

From the host package, `import "./math";` loads the public namespace of that entry point. A host can also
register the module under `dependencies` and import it by alias. Implementation files and the configuration
file are private to the directory module. The module can import ordinary source files from its host package.

All package types now require an explicit, nonempty `root`. Add a `root` field to configurations that previously
relied on the package name to select an entry point. The `version` field remains optional for all package types.

The entry point can choose which package information to expose. For example, an entry point next to
`package.jiang` can publish a version constant.

```jiang
import "package.jiang";

public const UInt8[]& version = package.info.version;
```

## Compiler and editor

- The language server resolves directory imports to their source entry points and includes re-exported
  declarations in completion.
- Read-only storage created for compile-time evaluation enters the output when referenced by emitted code.
  Exporting a standalone version constant can keep the rest of the package configuration out of the binary.
- Callable and coroutine changes include support for Send callables and corrections to ownership during
  coroutine transfer.
- Compile-time evaluation supports adapting `RawFn` to `Fn` and dropping the `send` guarantee from a callable
  value. Function type reflection preserves async domain bindings when the compiler reuses cached interfaces.

The existing [VS Code extension](https://github.com/jjcfun/vscode-jiang) uses these improvements when it starts
the 0.6.1 CLI.

## Building from source

The release bootstrap chain is **0.6.0 stable → 0.6.1-bootstrap → 0.6.1 next → 0.6.1 stable**.
The `0.6.1-bootstrap` tag contains the fixed transition source. See the
[build guide](../build-and-test.md) for the pinned seed archives and toolchain.

## Install

The release provides packages for macOS arm64 and Linux x86_64.

```bash
curl -fsSL https://github.com/jjcfun/jiang/releases/download/0.6.1/install.sh | bash
. "$HOME/.jiang/env"
jiang --version
```
