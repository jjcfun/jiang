# Jiang 0.5.6

Jiang 0.5.6 is a compatibility and correctness release based directly on Jiang 0.5.5. It provides
prebuilt packages for macOS arm64 and Linux x86_64.

## Language

- Function parameter defaults can use ordinary declaration-scope expressions, including function calls and arithmetic.
  The expression is evaluated at each call site where the argument is omitted. Passing the argument
  explicitly does not evaluate its default.
- Public functions preserve default expressions across module interface caches, so cached dependencies
  behave the same as source modules.

```jiang
Int next_value() {
    40 + 2
}

Int answer(Int value = next_value()) {
    value
}

assert(answer() == 42);
assert(answer(7) == 7);
```

## Correctness fixes

- Fixed restoration of associated type defaults and inherited static members from cached module interfaces.
- Fixed invalid LLVM atomic operations on `Bool` while keeping ordinary Boolean expressions compact.
- Fixed ownership and destruction checks around consuming receivers, async values and `Task` results.
- Fixed a cancellation race that could resubmit a suspended coroutine frame.

## Runtime

- macOS asynchronous domains now use reusable pthread workers instead of libdispatch for ordinary queues.
  Shutdown waits for accepted work to finish.
- The main domain remains integrated with the macOS main event loop.

## Building from source

The fixed bootstrap chain is 0.5.5 stable → 0.5.6 next → 0.5.6 stable. No transition compiler is required.

## Install

Download the archive for the current platform and the SHA-256 checksum file from the
[Jiang 0.5.6 release](https://github.com/jjcfun/jiang/releases/tag/0.5.6), then run:

```bash
cd jiang-0.5.6-<platform>
./install.sh
```

The default prefix is `~/.jiang`; the primary command is `jiang`, with `jiangc` retained as a
compatibility link.
