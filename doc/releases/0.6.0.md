# Jiang 0.6.0

Jiang 0.6.0 introduces a language server and editor support built on the compiler's existing parser,
semantic model, and query engine. Compiler concurrency changes are not part of this release.

## Language server

Run `jiang lsp` to start the persistent stdio language server. It supports:

- Diagnostics for unsaved files, with document versions and UTF-16 positions.
- Go to Definition across files and Hover with types and documentation from `///` and `#doc` blocks.
- Completion for declarations, function parameters, local variables, namespace declarations,
  instance members, and applicable extension members.
- Enum case suggestions after `.` in local declarations with an explicit enum type.
- Package configuration, source overlays, and diagnostic updates for related open files.

Editor checks prioritize the edited or requested file. Dependency signatures, defaults, and compile-time
evaluation are prepared on demand. Saving runs the complete checking pipeline, including ownership
diagnostics. Incomplete member expressions preserve usable semantic information for completion.

Successful syntax and stable declaration fingerprints are reused within each compiler session.
Compilation and editor sessions retain separate caches. Cached module interfaces preserve lambda
identities when restoring declarations or returning to source analysis.

## API documentation

Use `/// text` for single-line declaration and function documentation. Use `#doc` on its own line,
followed by Markdown and an isolated `#end`, for multiline documentation. Module documentation uses
`#doc(module)` with the same block form. Existing single-line `#doc text` must be migrated to `/// text`.
Both forms are available to reflection and language server Hover.

## Standard output

`print(value)` prints one value followed by a newline. It is available through the automatic prelude,
`std.print`, and `std.io.print`. Builtin text, numeric, and Boolean values are supported; borrowed custom
values use `Formattable.format(self, StringBuilder&! out)`. Byte slices replace invalid UTF-8 sequences
with U+FFFD; validated `String` values are preserved. Output failure causes panic.

## Compiler fixes

- Forward expression aliases can call functions declared later without a false alias cycle.
- Local values and pattern bindings take precedence over module aliases in member calls.
- Payload enum discriminants are converted to the declared integer width before storing the result.
- Release builds preserve allocation failure checks even when the allocated storage is unused.
- Vector growth remains available during compile-time evaluation, including source generators.
- Extension discovery preserves deferred diagnostics for unused missing imports.
- macOS process redirection sets close-on-exec with the correct platform calling convention.

## VS Code

Install the Jiang Language extension maintained in the
[vscode-jiang repository](https://github.com/jjcfun/vscode-jiang), and install the Jiang CLI separately.
The extension starts `jiang lsp` from `PATH`; `jiang.serverPath` can select a CLI executable or its bin
directory. The CLI package includes the standard library and builtin sources, so users do not need
the compiler source repository.

## Current limits

- Message handling and updates to other open files remain synchronous. Cancellation notifications do
  not interrupt an ongoing check.
- Completion does not yet precisely filter every lexical block scope.
- Expected-type enum suggestions currently cover explicit enum local declarations; they are not
  general expected-type completion in every expression context.
- Editor checks provide frontend diagnostics; saving is required for later ownership diagnostics.

## Building from source

The strict bootstrap chain is **0.5.6 stable → 0.6.0 next → 0.6.0 stable**. No transition compiler is
required. Use the released 0.5.6 compiler and the pinned LLVM 22.1.8 toolchain.

## Install

Install the latest release on macOS Apple Silicon or Linux x86_64:

```bash
curl -fsSL https://github.com/jjcfun/jiang/releases/latest/download/install.sh | bash && . "$HOME/.jiang/env"
```

The installer detects the platform, verifies the archive checksum, and configures PATH for Bash or Zsh.
Archives also include `install.sh` for manual installation. Packaged compiler resources are located
relative to the executable, so programs can be compiled outside the source repository.

The default prefix is `~/.jiang`. Add `~/.jiang/bin` to `PATH`; the primary command is `jiang`, with
`jiangc` retained as a compatibility link.
